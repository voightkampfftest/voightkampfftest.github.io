### Co usunięto:
- Google Fonts (Inter, JetBrains Mono, Syne, Space Grotesk) — 0KB teraz
- Hero section z parallax, CRT scanlines, cyan filter
- SVG geometryczne ikony z service cards
- Tech pill badges → tekst oddzielony przecinkami
- About 2-column grid z info card sidebar → single column z definition list
- Social SVG icons w footer → tekstowe linki
- Pusta sekcja blog
- Cienie, border-radius, gradienty, animacje CSS
- Hide-on-scroll nawigacja
- Sticky nawigacja
- Buttony .btn-primary/.btn-secondary
- Utility classes (.flex-*, .grid-*, .mt-*, .mb-*)

### Co zachowano:
- Dark/light mode toggle
- PL/EN language toggle
- Expandable project cards (z CSS grid-template-rows animacją)
- Mobile hamburger menu
- Active section detection (IntersectionObserver)
- Smooth scroll
- Accessibility (focus-visible, ARIA labels, keyboard nav)

### Design principles:
- max-width: 70ch — nigdy px dla szerokości tekstu
- Spacing: wielokrotności baseline 1.5rem
- Zero border-radius, box-shadow, text-shadow
- Zero gradientów, zero animacji (oprócz expand/collapse)
- Linki z text-decoration: underline
- System fonts — zero external fonts
